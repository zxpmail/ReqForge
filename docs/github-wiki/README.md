# GitHub Wiki 源稿

本目录 **不是** 自动同步到 [GitHub Wiki](https://github.com/zxpmail/ReqForge/wiki) 的内容；维护者手动更新 Wiki 时使用。

## 发布步骤

1. 打开仓库 **Wiki** → **New Page** 或编辑 [Home](https://github.com/zxpmail/ReqForge/wiki/Home)
2. 将 [`Home.md`](./Home.md) 全文粘贴为 Wiki 正文（GitHub Wiki 使用 Markdown）
3. 保存；链接请保持为仓库 `main` 分支的绝对 URL（稿中已写好）

## 与 README 的关系

| 文档 | 用途 |
|------|------|
| [README.zh-CN.md](https://github.com/zxpmail/ReqForge/blob/main/README.zh-CN.md) | 完整说明（主文档） |
| `docs/github-wiki/Home.md` | Wiki 首页摘要 + 导航（轻量） |

版本与 README 徽章对齐时请同步修改 `Home.md` 顶部的版本行。
