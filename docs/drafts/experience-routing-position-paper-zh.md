## 摘要

在**白盒可观测 worker**的多工异步 RL 中，优化器与协作界面之间常缺一层：**轨迹生成后，谁可物化、以何种粒度、何时可更新 \(\theta\)**。黑盒 API 不在强形式主张内。

本文称该层为**经验准入控制**（下称**准入策略**）。新意在 **P1–P4**（proposed admission policy）与预注册失败条件，而非新打分或已证发现。假说级主张：瓶颈常在经验如何分层、隔离、低频进入基座更新路径，而非更多模型彼此可见。

**判定分层：** 固定 \(\mathcal{A}\)，仅改数据平面（A/B/P）。未触失败条件 4/5、物化成本↓、无持续回撤 → **§6.4 启动**（可放大，≠验证，≠必须一等模块）。放大后仍通过 → 建议做成管线一等模块；否则撤回该配置强形式（命名可停用）。

**关键词：** experience admission；proposed admission policy；white-box multi-worker RL；dataflow；falsification

## 1. 引言

多 worker、异步、长时程 RL 讨论中常混写三个问题层。

**优化层**关心梯度如何被计算和应用（如组相对方法 [2]、单 rollout 异步优化 [1]）。**协作层**关心多个 worker 在交互期如何共享上下文、文件和会话状态。**准入层**回答的是另一件事：轨迹已生成之后，谁可物化、以何种粒度物化、何时可更新 \(\theta\)。

优化器回答「何时/如何更新」。协作界面回答「如何配合」。二者都不直接定义准入语义。吞吐上升仍可能无差别暴露噪声与高风险轨迹；共享上下文不自动给出隔离规则。**训练稳定性与经验准入语义相关但不等同：** 稳定性问的是给定可见集上更新是否发散；准入问的是哪些轨迹允许进入该可见集、进入前是否/如何物化。优化器可以把脏可见集学得更稳，却不回答可见集的策略边界。

**适用范围（先收窄再谈动机）。** 本文强形式假设 worker 可暴露隐藏表示、局部动作分布或不确定性信号之一。这覆盖自部署开源权重与可观测 actor–learner，**不覆盖**主流闭源 API agent——后者至多退化为后验文本筛选，**不与强形式混称，也不在主张内**。LLM agent 是动机场景之一，但验证域是白盒可观测设定。

在该设定下，问题不限于 LLM：长轨迹、异步、异质 worker 在经典深度 RL 中同样存在。IMPALA [5] 与 Hou 等 [1] 属优化/调度平面，可默认「送达即可学」。本文命名的是送达之后的**准入策略**。Shielding [9] 收缩动作可行性；CQL [6] 约束给定数据集上的价值估计——均不回答在线流上的分层物化/更新预算。

**C1 最小反例（为何「开着 PER」仍不够）。** 设 buffer 中同时存在普通可学轨迹 \(\tau^+\)，以及高风险但高 TD-error / 高惊讶度的 \(\tau^\ddagger\)。PER [3] 按 TD-error 重加权时，若 \(\tau^\ddagger\) 处于优先级高分位，则可被以高于均匀采样的频率采样进更新 batch[^per-quantile]；推理期 shield 若只拦不安全*动作*，并不从训练可见集移出 \(\tau^\ddagger\)；删除式过滤丢掉分析价值。三联缺口：P1 预算语义缺席（轨迹已在池中被默认可学，无「默认不物化」约束）/ 违 P2·P4 / 违 P3。语义缺口：采样权重 ≠ 准入策略。

[^per-quantile]: PER 的采样概率与优先级分位成幂律关系，因此高分位不保证一定被采样；但重加权机制原则上允许高风险样本以高于均匀的频率进入 learner——这种机制上的「允许」正是本文所称的语义缺口。另：若危险轨迹 TD-error 并不高，PER 不会提高其采样概率——但这不构成对准入层的反驳：此时危险经验只是「未被注意」，而非「被策略层隔离并保留」；P2 的区别不在于「不被学」，而在于「被标记、被保留、可分析」。

因此：本文不是要替代优化器或协作层，而是主张在它们之间增加一个显式数据平面。结构：贡献 → P1–P4 与逻辑互依（§3）→ 近邻（§3.1）→ 接口与谓词（§4）→ 假说（§5）→ 可证伪协议（§6）→ 反对意见（§7）→ 结论。

## 2. 贡献与非主张

本文是技术立场文，不是方法论文。

**贡献一：问题重述。** 将「轨迹生成之后谁可物化、以何种粒度物化、何时可更新 \(\theta\)」提升为独立系统层。若命名可被既有术语完全吸收，则**停用该命名**。即便停用命名，P1–P4 与 §6 协议仍可作为**系统接口**独立检验。

**贡献二：提议的准入策略 P1–P4。** 给出相对 PER/删除式过滤的最小*设计差异集*，并附逻辑互依论证（§3.2）。新意压在四条可开关约束上，而非指纹公式。**不声称**已用因果消融证明经验最小性。

**贡献三：可证伪协议。** A/B（及 PER 对照）与五条预注册失败条件；条件 5 可判定当前代理族上的强形式配置失败（§6）。

**不声称：** 理论保证；因果不可约已证；协作产品作 RL baseline；占位参数最优；强形式覆盖黑盒 API；LoRA/云端微调主结果；附录作已证方法结论；§6.4 启动条件等于验证成功或「必须做成一等模块」。

## 3. 提议的准入策略：为何不是「换名的 PER/filtering」

**术语（物化 vs 深读）。** 本文中「物化」指将轨迹从流式状态转为可检视的持久化对象；「深读」指对物化后的轨迹执行高成本分析（如完整展开、回放、价值估计）。在多数实现中二者同属「准入成本」，但逻辑上可分离——可先物化后深读，也可在流式状态上深读后丢弃。为简洁起见，预算与指标语境下统称「物化成本」；需区分时，「物化」为存储侧，「深读」为计算侧。\(D_{\mathrm{read}}\) 表示可被物化/深读的可见集，不等于已准入更新。

若批评者问去掉名称后还剩什么，答案落在四条**设计约束**。**同时作为策略被执行**时，方值得使用「经验准入控制」；任一长期缺失则停用该命名。它们是 **proposed admission policy**，不是已发表的科学发现。

| 约束 | 含义 | PER 通常有？ | 删除式安全过滤通常有？ |
|------|------|-------------|------------------------|
| **P1 默认不物化** | 完整物化默认关闭，需显式授权与配额 | 否 | 否（常在已物化轨迹上判决） |
| **P2 隔离 ≠ 删除** | 高风险轨迹可禁止进入 \(D_{\mathrm{adm}}\)，但保留分析价值 | 否 | 通常否（拦截或丢弃） |
| **P3 物化 ≠ 准入** | 展开/检视 ≠ 获得更新 \(\theta\) 的权限 | 否（被采样 ⇒ 被学习） | 部分；很少分离观察与更新 |
| **P4 可见集真包含** | 当 hot 非空时 \(D_{\mathrm{adm}} \subsetneq D_{\mathrm{all}}\)，不是「全体可学、仅重加权」 | 否 | 否（收缩动作，不定义训练可见集） |

**P4 边界。** hot 为空时集合上可有 \(D_{\mathrm{adm}}=D_{\mathrm{all}}\)，但强形式仍要求 P1/P3，且一旦出现 hot-hazard 须恢复真包含。长期「hot 空 + 全体默认可学」= 未实现准入层。

**为何不合并 P1 与 P3。** 逻辑可分：可物化但不准入；「未物化却准入」危险。**强形式禁止后者为默认路径**：摘要至多用于路由/晋升提议；进入 \(D_{\mathrm{adm}}\) 须独立验证（§4）。命名上必须分开，否则无法逐条消融（§8）。

PER 可作 warm 排序器；shield 可检 hazard——都不自动给出整套准入策略。只做 TD-error 重加权却称 admission，是命名过度。

### 3.1 近邻：为何也不是「换名的 LLM 数据筛选」

LLM 后训练中的 preference filtering [10]、RLAIF [11]、RAFT 类拒绝采样 [12]、对齐流水线 filter [13] 优化的是进 batch 前的质量与标注成本，通常默认：留下即可更新 \(\theta\)，丢掉即不再参与训练。

| 近邻 | 通常优化什么 | 仍缺什么 |
|------|--------------|----------|
| Filtering [10] | 去噪、偏好数据质量 | 少分离可检视/可更新；丢弃 ≠ 隔离保留 |
| RLAIF [11] | AI 反馈缩放标签 | 不定义训练可见集策略 |
| RAFT 类 [12] | 只训高分 completion | 二元删留；**高分 ≠ 低风险**；无 quarantine 轨 |
| Alignment filter [13] | 工程数据清洁 | 无多 worker 物化预算与 hot→\(\theta\) 硬约束 |

近邻是实现组件；不是同一对象。多阶段探索（如 First Return, Then Explore [4]）表明长时程中「先返回再探索」等分阶段策略可以有效，但其对象是**探索日程与状态覆盖**，并不定义物化预算、隔离保留轨，或 \(D_{\mathrm{adm}}\) 相对 \(D_{\mathrm{all}}\) 的强制真包含——故与本文准入策略正交，而非替代。

### 3.2 逻辑互依（反事实）：为何四条要一起提

以下论证**逻辑最小性**，不是因果消融实验。经验上是否真不可约，仍属 §8。

| 反事实 | 策略退化成 | 因此 |
|--------|------------|------|
| **去 P1，留 P2–P4** | 物化预算约束消失 → warm/hot 分区失去预算意义，只剩「是否被标记」的标签层；行为上贴近无物化配额的混合缓存（仍可能保留隔离标签） | 无预算约束则相对被动池的成本差异难成立 |
| **去 P2，留其余** | 高风险只能删除或当普通样本学 → 退化成 delete-filter / 无分析轨（近 shielding+丢弃） | 无 P2 则「隔离利用」消失 |
| **去 P3，留其余** | \(D_{\mathrm{read}}\equiv D_{\mathrm{adm}}\)：被看见即被学 → 行为上贴近 PER/被动池 | 无 P3 则回到采样即学习 |
| **去 P4，留其余** | 名义三区与 P1–P3 可仍在，但当 hot 非空时**不再强制** \(D_{\mathrm{adm}}\subsetneq D_{\mathrm{all}}\)：退化至「带预算/隔离/物化-更新分离、却无强制可见集真包含的混合缓存」——与 PER **仍有区别**，却已失去可见集层面的策略层差异 | 无 P4 则真包含不可强制执行；**不等于**退回纯 PER |

**为何四条要一起启用（设计层）：** 四条分别堵住「默认物化 / 只能删或学 / 看见即学 / 无可见集硬约束」四类退化；任一缺失，剩余条款无法单独支撑准入层的**完整**声称。这说明 P1–P4 作为**提议清单**应一起提出并一起检验；去掉 P4 **不等于**退回纯 PER，但等于放弃可见集策略的完整规格。**不**等于已用介入实验证明它们是世界上唯一的最小集。

**已知局限（经验层）：** 尚未提供因果消融证明哪条约束驱动相对 PER 的行为差异。聚合 A/B/PER 胜出不替代逐条机制验证（§8）。逻辑互依不填补该缺口，只避免「随机四条工程直觉」的指控。

## 4. 最小接口描述与准入谓词

不给出完整算法或形式系统。固定**接口 + 最小谓词约束**，使对象可讨论、可实现。

数据流：

\[
\tau \xrightarrow{\phi} x \xrightarrow{r} \mathcal{B} \xrightarrow{\mathrm{adm}} D_{\mathrm{adm}} \xrightarrow{\mathcal{A}} \theta
\]

\(\mathrm{adm}\) 表示由 P1–P4 约束的准入映射；可选审核 `gate` 仅为实现组件。

- **\(\phi\)：** 廉价、流式、局部（C3 占位，可替换；不计贡献）。
- **\(r(x_t)\in\{\mathrm{archive},\mathrm{warm},\mathrm{hot}\}\)：** 回答谁可物化、谁不可用于更新 \(\theta\)，而非「谁更重要」。
- **\(\ell(\tau)\in\{\texttt{promising},\texttt{hazard}\}\)：** 可晚于隔离赋予。
- **集合：** \(D_{\mathrm{read}}\) 与 \(D_{\mathrm{adm}}\) 策略分离；\(D_{\mathrm{restricted}}\) 排除 hot-hazard；hot 非空时 \(D_{\mathrm{adm}}\subsetneq D_{\mathrm{all}}\)，且恒有 \(D_{\mathrm{adm}}\subseteq D_{\mathrm{restricted}}\)。

### 4.1 最小准入谓词

\[
\tau \in D_{\mathrm{adm}} \iff \mathrm{Validated}(\tau) \land \lnot\mathrm{HotHazard}(\tau) \land \mathrm{InBudget}(\tau)
\]

其中 \(\mathrm{HotHazard}(\tau) \iff \bigl(r(\tau)=\mathrm{hot}\land \ell(\tau)=\texttt{hazard}\bigr)\)；\(\mathrm{Validated}\) 为独立于路由分数的晋升验证；\(\mathrm{InBudget}\) 编码**物化配额**（P1）及晋升通道上的容量上限（实现细节，与 P3/P4 门控配合，不单属 P1）。

**与 \(\mathcal{A}\) 的交互约束：** 对任意更新步 \(t\)，优化器所用 batch 满足 \(B_t \subseteq D_{\mathrm{adm}}\)。\(\mathcal{A}\) **不必**内化准入语义；只需保证其输入集已被准入层约束。若 \(B_t\not\subseteq D_{\mathrm{adm}}\)，则属**契约违反**；若违规 batch 中含 hot-hazard，则同时触发 §6.3 条件 4。

### 4.2 最小实现契约

1. hot-hazard 不得进入更新 \(\theta\) 的 batch。  
2. 物化发生在 \(D_{\mathrm{read}}\)；写入 \(\theta\) 仅经由 \(D_{\mathrm{adm}}\)（P3）。  
3. 晋升须经独立于路由分数的验证。  
4. archive 默认不物化；warm 物化受预算约束（P1）。  
5. 可选 gate 不得扩大上述允许集合。

**强形式假设：** worker 可观测信号之一；否则为黑盒退化，不在主张内。禁止「未物化却准入」为默认路径。

## 5. 可检验假说

以下构成 C2 的可操作版本。**主协议（§6）检验 H1/H2/H4，以及 P2 的最低执行完整性（条件 4：隔离禁入 + 隔离区非空则须被读取/用于外围分析）。H3 检验的是隔离保留的「可测外围价值」幅度，属探索性，不进入 §6.4。**

**H1（主）：** 粗路由 + 选择性物化，相对被动池降低物化量且维持任务表现。  
**H2（主）：** 三区相对二元滤波，保留可分析异常且不增加基座污染。  
**H3（探索性）：** 隔离保留相对直接丢弃，在离线监测/判别器上产生**可测正价值**——条件 4 已禁止「隔离但永不读」；H3 进一步问「读了是否有用」，**不作为 §6.4 必要项**。  
**H4（主）：** 「低频」= **对基座的更新接触频率与可见集大小**受限，不是学习率/SGD 步数；受限更新相对默认开放更稳定。

### 5.1 H ↔ P

| 假说 | 主要依赖 | 失败时优先怀疑 | 协议地位 |
|------|----------|----------------|----------|
| H1 | P1 | 条件 5 或条件 1 | 主 |
| H2 | P2+P4 | 退化二元删留；hot 仍进更新 | 主 |
| H3 | P2（价值幅度） | 有读取仍无外围增益 | 探索性（§8）；完整执行靠条件 4(b) |
| H4 | P3+P4 | 物化即写入；更新接触频率≈被动池 | 主 |

§6 检验主假说聚合效应；H3 与逐条 P 消融属 §8。

## 6. 预注册可证伪协议

### 6.1 比较

同一 \(\mathcal{A}\)、任务、worker 类：

| Arm | 数据流 |
|-----|--------|
| A | 被动池：默认可物化/可入 replay |
| B | 准入：P1–P4 + §4 契约/谓词 |
| P | 同 buffer 上 PER——采样权重，非准入语义 |

### 6.2 核心指标（最小操作定义）

| 指标 | 定义 |
|------|------|
| 有效物化比 | 物化/展开量 ÷ 生成总量 |
| 墙钟/FLOPs | 达成分段回报阈值的成本 |
| 任务回报 | 与 A 同协议 |
| 危险穿透率 | 更新 batch 中 hazard/hot-hazard 占比 |
| 物化增益 | 在预注册 held-out 探针上，物化后相对物化前的回报改善或损失下降（择一固定）。**允许**对预注册轨迹子集取均值/中位数，或对增益做预注册平滑（如滑动窗口），以降低单轨迹噪声；具体聚合方式实验计划中固定，不得事后改。仅作条件 5 标签，不单独构成成功标准 |
| 信号–增益 \(\rho\) | 校准后路由分 vs（聚合/平滑后的）物化增益的 Spearman |

### 6.3 失败条件

窗口 \(K\geq 3\) 段（计划中固定）。**任一触发**，即判定该设定下立场不成立。

1. **warm 区塌缩**——warm **流量**占比 \(\geq 90\%\)（或 archive+hot 合计 \(<10\%\)），且相对 A 的有效物化比改善 \(<5\%\)。warm 流量占比 = 窗口内路由至 warm 的轨迹数（或转移数；口径预注册）÷ 同期生成总量。  
   *口径：* 流量 = 路由计数；有效物化比 = 实际成本。二者可不等价。条件 1 为合取：流量堆在 warm **且**物化成本未实质下降才触发；流量高但成本已明显下降则**不**触发。  
2. **无预算改善**——物化比改善 \(<10\%\) 且墙钟/FLOPs 改善 \(<5\%\)（默认 **AND**；与条件 1 分工：1 抓「名义分区+成本未降」，2 抓「整体相对 A 无实质预算收益」）。  
   *灰色地带：* 物化比改善 \(\in[5\%,10\%)\)（或 \(<5\%\) 但未触条件 1）且墙钟改善 \(\geq 5\%\) 时，条件 1–2 均可不触发，但亦不满足 §6.4（需物化比 \(\geq 10\%\)）——**不得宣称启动通过**，亦不得事后改阈。若要以替代联合判据（如加权 OR、或声明「墙钟补偿物化比」）判定失败/通过，须在预注册中显式固定；否则条件 2 按 AND 执行。  
3. \(K\) 段中 \(\geq\lceil 2K/3\rceil\) 段回报显著低于 A（预注册 \(\alpha\)/MID）。  
4. **硬（P2 完整性）：** （a）任一 hot-hazard 进入 \(D_{\mathrm{adm}}\) 并更新 \(\theta\)；**或**（b）评估窗口内隔离区（hot，或预注册的 quarantine 集合）**非空**，但其中轨迹**从未**被读取/深读，也**未**用于任何预注册的外围分析（监测、判别器、审计日志等）——视为「隔离但遗忘」，P2 执行不完整，硬失败。hot 为空时（b）不适用。  
5. **硬（proxy–gain 检验）**——检验当前预注册代理族是否仍携带可学习信息（见 §7.2），分三款；**任一子款触发即判定条件 5 失败**（须检齐三款，不得只报通过的子款）：  
   - **相关：** 校准后 Spearman \(\rho\)（路由分 vs 物化增益）做单侧检验，备择 \(\rho>0\)；预注册 \(\alpha\)（如 \(0.05\)），不得事后改。不显著 → 触发。  
   - **随机基线：** 在相同 archive 边际频率下 i.i.d. 均匀打 archive/非 archive 标签；路由与该基线在「是否 archive」上的 F1/准确率差 \(<\delta\)（\(\delta\) 预注册）→ 视为≈随机 → 触发。  
   - **代理族边界：** 「换族」= 分数函数**架构级**变更（如熵→预测误差，或固定特征→可学习投影）。同函数内调阈值/归一化/窗口 = **同一配置**，须重跑检验，不得改名规避。失败后至多保留弱后验筛选，不得与强形式混称；新族须重新预注册，不继承旧结果。

### 6.4 启动条件（放大实验门，≠ 验证成功）

相对 A：有效物化比改善 \(\geq 10\%\)；条件 3 未触发；条件 4–5 未触发（含 4(b)：隔离非空则须被读取/用于外围分析）。

**定性：** 仅表示**未触发失败条件**，允许投入更大规模实验。**不**等于验证成功，**不**等于「弱成功」，**不**单独推出「必须做成一等模块」。样本量小或方差大时尤不能当作效力证明。H3 的「可测正价值」仍待放大阶段或 §8，不由启动门单独断言。  
**设计建议（规范层，非协议结论）：** 若启动后放大实验仍维持通过，再建议把准入策略做成训练管线一等模块，而非默认被动池/PER。

（可选观察：物化比改善 \(\geq 10\%\) 且回报不低于 A 的预注册 MID——仍不升格为主声称。）

## 7. 反对意见

### 7.1 「不过是换名的 replay/filtering」

压到 §3 的 P1–P4 与 §3.2 逻辑互依。若可被既有术语完全吸收，停用该命名。接口仍可按 §2/§6 检验。经验因果分解仍缺（§8）。

### 7.2 「廉价信号未必与可学习价值相关」

这是强形式最深的统计脆弱性。ICM/RND [7,8] 表明不确定性信号与学习状态在短时程设定下**有先验相关性**；长时程 agentic 下**某一预注册代理族**是否仍相关，是开放问题——条件 5 正是为检验它而设。若相关建立不起来，判定失败的是**该代理族上的强形式配置**，不调阈值续命。仅当发生**架构级**代理变更（见 §6.3）时，方可预注册为新族并重跑协议；同函数内调参不算新族。至多保留弱后验筛选。

### 7.3 「没有理论也没有够硬的实验」

主文可辩护：提议策略 + 逻辑互依 + 可证伪协议。不把附录当第三层。要求消融/LLM 主结果 → 承认 §8，不吹数字。

### 7.4 「白盒太窄，动机却写得很宽」

接受收窄：标题与摘要已限定白盒可观测。云端黑盒 API 是真实主流实践，但是**另一篇弱形式问题**；本文不强行覆盖。

### 7.5 适用范围边界（非正式）

本协议面向长时程、高物化/深读成本、异质 worker 的 RL 场景。若轨迹短（例如平均长度 \(L<100\)）、单 worker、物化成本可忽略，准入层的额外系统复杂度可能超过收益；此时被动池或 PER 仍是合理默认。即便某次实验通过 §6，设计者仍可因工程成本选择不启用——通过只说明「该设定下假说未被证伪」，不强制全面替代。本文主张的是：在合适场景下把准入层作为一个**显式设计维度**，而非万能默认。

## 结论

在白盒可观测多工异步 RL 中，优化器与协作界面之间有一层常被忽略的经验数据流组织问题。本文将其命名为经验准入控制，并提出 P1–P4 作为**提议的准入策略**（附逻辑互依与可证伪协议）。是否在经验上成立是开放问题。

**可检验判定标准（分层）：** 固定 \(\mathcal{A}\)，仅改数据平面。满足 §6.4 启动条件 → 允许放大实验，**不等于**验证成功，也**不**单独蕴含「必须做成一等模块」。若放大后仍维持通过，再作为**设计建议**把准入策略做成训练管线一等模块；否则撤回该配置的强形式主张。

争取的不是「已证明正确」，而是公开一个可检验可证伪的问题：**在可观测 worker 上，经验是否应当以分层、隔离、低频的方式进入基座更新路径。**
