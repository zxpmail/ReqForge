# Product Spec: 小说创作工作台

## 产品概述
一款面向网络小说作者的 Web 端写作规划工具，支持从人物设定到章节生成的全流程。用户自主构思，AI 辅助生成素材和正文。

## 目标用户
- 自己写网络小说的作者
- 题材：现代言情、都市、穿越等

## 核心功能

### 1. 人物关系网
- 创建小说角色，填写姓名、年龄、性格、背景等基本信息
- 建立角色之间的关系（情侣、仇人、朋友、亲属等）
- 可视化展示人物关系图谱
- 支持拖拽调整布局
- 关系网可修改、可扩展

### 2. 章节大纲
- AI 根据人物设定和题材自动生成章节大纲
- 分章管理，每章可设标题和摘要
- 支持手动调整大纲结构
- 大纲可折叠展开

### 3. 正文写作
- AI 根据审核通过的大纲生成正文内容
- 逐章生成，每次生成一章
- 支持 AI 续写、重写指定段落
- 支持手动编辑修改

### 4. 项目管理
- 多作品管理（同时写多本小说）
- 每本小说独立管理人物库和大纲
- 作品基本信息设置

### 5. 存储
- 纯本地存储，所有数据保存在浏览器中
- 导出 / 导入功能，支持备份

## 用户流程
1. 创建新作品 → 设置题材和背景
2. 创建人物 → 设定关系和属性
3. AI 生成人物关系网 → 用户审核调整
4. AI 生成章节大纲 → 用户审核调整
5. 确认后 AI 逐章生成正文
6. 用户编辑修改，完成作品

## 技术要求
- 纯前端 Web 应用
- 数据存储在 IndexedDB / localStorage
- 支持数据导出为 JSON / Markdown
