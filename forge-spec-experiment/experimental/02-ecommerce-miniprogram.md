# Product Spec: 手工艺品社区电商小程序

## 产品概述
个人手工艺者的微信小程序电商。**关键矛盾**: 客户说"想先用简单的方式做起来"，但需求列表中包含直播带货、推荐系统、会员体系 — 这些都不简单。

## 目标用户
- 25-45 岁女性消费者，手工艺品爱好者
- **假设**: 单人经营的品类宽度和库存深度，能否支撑"分类浏览"（陶瓷、木工、布艺）？一个人同时做三种手艺的供应链几乎不可能
- **建议**: 确认是自产自销还是平台模式。如果是自产，初期只做一个品类更现实

## 核心功能

### 1. 商品展示
- 商品列表 + 分类筛选 + 详情页
- **未说明**: 商品图片谁拍？手工艺品的展示质量直接影响转化率

### 2. 下单购买
- 购物车 → 下单 → 微信支付
- **风险**: 微信小程序对个人主体的支付能力有限制（不支持虚拟商品、部分类目受限）。手工艺品属于"零售"通常可过审，但需确认

### 3. 订单管理
- 基础订单 CRUD
- **未说明**: 发货物流 — 手工艺品通常是快递发货，是否需要对接物流单号追踪？

### 4. 用户系统
- 微信一键登录
- **风险**: 个人小程序无法使用部分高级能力

### 5. 直播带货
- **不可行**: 微信小程序直播需要企业主体 + 资质审核，个人主体无法开通。且直播需要运营、场地、设备，单人经营基本不可能
- **替代方案**: 用视频号直播，外链到小程序商品

### 6. 会员体系
- **模糊需求**: "积分什么的"是个 placeholder，不是需求。会员体系的前提是有足够的用户复购频次，初期用户少量时做了也没用
- **建议**: v1 不做，等日活 >100 再考虑

### 7. 个性化推荐
- **不可行**: 推荐系统需要用户行为数据积累和算法模型。单人个体户没有这个资源
- **替代方案**: 手动"掌柜推荐"或按销量排序

## 范围裁剪建议
| 版本 | 功能 | 说明 |
|------|------|------|
| v1 | 商品展示 + 下单 + 微信支付 + 订单管理 + 微信登录 | 3-4 周 |
| v2 | 物流追踪 + 商品评价 + 基础营销（优惠券） | 2 周 |
| 不做 | 直播带货、推荐系统、会员体系 | 实际条件不具备 |

## 风险矩阵
| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| 个人主体小程序支付/类目限制 | 高 | 项目无法上线 | 先用有赞/微店验证，再考虑自建 |
| 单人经营无法同时维护多品类 | 中 | 商品线太薄 | 初期聚焦一个品类 |
| 用户获取成本高 | 高 | 无人下单 | 需要抖音/小红书引流方案，不能只靠小程序 |

## 前提条件
1. 确认微信小程序主体类型（个人 vs 企业），个人主体有功能限制
2. 商品供应链（自产 vs 货源）和品类策略明确
3. 如无设计能力，需外包商品拍摄和页面设计
4. **建议先用已有平台验证商业模式**，再投入开发
