# Command: /design-brief-builder

Design direction interview workflow. Full procedure in SKILL.md.

## Phase 1: Anchor & Constraints
**Goal**: Translate vague preferences into concrete design direction
- Read Product-Spec.md for product context and UI scope
- Offer 2–3 reference-product style options (never open-ended questions)
- Identify contradictions and force trade-offs
- **Acceptance**: User confirms a visual direction anchor

## Phase 2: Detail & Accessibility
**Goal**: Fill design-brief sections with actionable guidance
- Cover layout density, color mood, typography feel, interaction style
- Note accessibility basics (contrast, touch targets, hierarchy)
- WebSearch current trends for referenced products when needed
- **Acceptance**: All Design-Brief template sections populated

## Phase 3: Brief Generation
**Goal**: Write Design-Brief.md
- Generate from templates/design-brief-template.md
- Repeat back translated design language for user confirmation
- **Acceptance**: Design-Brief.md written, user confirms accuracy
