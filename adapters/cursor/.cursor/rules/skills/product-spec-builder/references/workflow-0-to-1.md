[Workflow (0-to-1 Mode)]

    **可选：Product Discovery（PM 框架）**
        - 触发：想法模糊、用户要求 brainstorm/discovery、或 outcome 未定义
        - 跳过：Quick Mode、用户已提供完整 brief、或明确「直接写需求」
        - 读取：`references/pm-frameworks-readme.md`，按需选用 OST / 假设 / 价值主张 / 竞品 之一或组合
        - 产出：对话摘要 + 在 Document Generation 写入 Spec 可选章节（见 template）
        - **不得**因 Discovery 跳过 HARD-GATE 与用户书面确认

    **主流程（按 SKILL.md 顺序）**
        1. [Requirements Exploration Phase]
        2. [Clarifying Questions Phase] — 可结合 `pm-frameworks-assumptions.md`
        3. [Requirements Refinement Phase]
        4. [Document Generation Phase] — 填充 `product-spec-template.md`（含 PM 可选小节）

    **渐进披露索引**
        - 维度清单 → `requirements-dimensions.md`
        - 对话策略 + CoT → `conversation-strategy.md` [Chain of Thought]
        - PM 框架 → `pm-frameworks-*.md`
        - 迭代模式 → `workflow-iteration.md`
