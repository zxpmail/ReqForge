# Command: /product-spec-builder

Guided requirements gathering workflow. Full procedure in SKILL.md.

## Phase 1: Discovery
**Goal**: Understand the product idea at a high level
- Ask targeted questions about purpose, target users, core value
- Identify if this is new project (0-to-1) or iteration on existing spec
- **Acceptance**: Clear one-paragraph product concept agreed with user

## Phase 2: Detail Gathering
**Goal**: Elicit complete functional requirements
- Walk through use cases, UI layout, user flows
- Identify AI capability needs and technical direction
- **Acceptance**: All Spec sections populated, no major ambiguities

## Phase 3: Spec Generation
**Goal**: Write or update Product-Spec.md
- Generate structured document from template
- For iterations: detect conflicts with existing spec, update changelog
- **Acceptance**: Product-Spec.md committed, user confirms accuracy
