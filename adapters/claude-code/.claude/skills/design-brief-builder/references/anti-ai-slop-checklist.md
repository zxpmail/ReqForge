# 反 AI 味清单（Anti–AI-Slop）

[Anti–AI-Slop Checklist]

勾选通过后再定稿；任一项为「是」须改 Brief 或回到访谈。

| 检查项 | 通过标准 |
|--------|----------|
| 渐变滥用 | 无「默认紫蓝对角渐变 Hero」作为唯一视觉手段 |
| 玻璃拟态堆叠 | 非多层半透明卡片套娃且无功能理由 |
| 假 3D / 无意义插画 | 插画服务信息或品牌，非装饰填充 |
| 字体层级 | 标题/正文/辅助至少 3 级，非全同字号 |
| 对标具体 | Reference 表写清「喜欢哪一点」，非只写产品名 |
| 密度与功能一致 | 功能多却强行「极简大面积留白」已解释折中 |
| 状态设计 | 空/加载/错误均有方向，非 [TBD] |
| 可执行性 | 开发能据此选 Tailwind/组件风格，非仅形容词 |

**Brief 末尾**：增加 `## Anti-Slop Review` — 列出已排除的 slop 模式（1–3 条即可）。
