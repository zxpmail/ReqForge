# Command: /bug-fixer

Entry: describe the bug or pass code-review findings. **Full workflow → `SKILL.md`** (evidence → hypothesis → fix).

| Phase | SKILL.md | Acceptance |
|-------|----------|------------|
| Evidence | Collection | Repro steps + logs clear |
| Root cause | Analysis | Cause confirmed with evidence |
| Fix | Fix & Verify | Tests pass; re-review with `change_complexity=simple` unless large change |
