# 反 AI 味清单（code-review）

<!-- 输出 review report 前自检，避免走过场式审查。 -->

[Anti–AI-Slop Checklist]

勾选通过后再提交 review report；任一项为「是」须补充分析。

| 检查项 | 通过标准 |
|--------|----------|
| 盖章式审查 | 非「LGTM / looks good」——每条 finding 有 file:line |
| 模糊表述 | 非「代码不够健壮」——说清什么场景下会怎样失败 |
| 偏见盲区 | 非「这文件没改，跳过」——未改文件也可能被上下文影响 |
| 安全错觉 | 非「没写 SQL 所以没安全问题」——XSS/路径泄露/凭据硬编码均检查 |
| 唯编译论 | 非「编译通过了所以没问题」——功能正确性 ≠ 编译通过 |
| 漏回归范围 | 非「其他功能应该不受影响」——显示列出回归 scope |
| 举报证 | 每条 must-fix 至少有 confidence 评级和影响描述 |
